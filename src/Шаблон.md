# Краткое объяснение использования шаблонов в Rust

## Что такое шаблоны?
Шаблоны — это способ сопоставления значений с определенными структурами. Они используются во многих конструкциях языка.

## Где используются шаблоны:

### 1. **match (сопоставление)**
```rust
match x {
    None => None,
    Some(i) => Some(i + 1),
}
```
Шаблоны: `None` и `Some(i)`. Должны покрывать **все** варианты (исчерпывающие).

### 2. **if let / else if / else if let**
```rust
if let Some(color) = favorite_color {
    println!("Цвет: {}", color);
} else if let Ok(age) = age_str.parse() {
    if age > 30 {
        println!("Фиолетовый");
    }
} else {
    println!("Синий");
}
```
Более гибко, чем `match`, но компилятор не проверяет полноту.

### 3. **while let (условный цикл)**
```rust
let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("{}", top); // 3, 2, 1
}
```
Выполняется, пока шаблон совпадает.

### 4. **for (цикл)**
```rust
let v = vec!['a', 'b', 'c'];
for (index, value) in v.iter().enumerate() {
    println!("{}: {}", index, value);
}
```
Шаблон `(index, value)` деструктурирует кортеж.

### 5. **let (присваивание)**
```rust
let (x, y, z) = (1, 2, 3); // x=1, y=2, z=3
```
Количество переменных должно совпадать с количеством элементов.

### 6. **Параметры функций**
```rust
fn print_coordinates(&(x, y): &(i32, i32)) {
    println!("Location: ({}, {})", x, y);
}
```
Деструктуризация кортежа в аргументах функции.

## Важное замечание:
Шаблоны бывают:
- **Неопровержимые** (всегда совпадают) — в `let`, параметрах функций
- **Опровержимые** (могут не совпасть) — в `if let`, `while let`
