# Продвинутые типы в Rust — кратко

## 1. **Newtype** (новый тип)
Оборачиваем существующий тип в структуру для **безопасности типов** и **инкапсуляции**.

```rust
struct Millimeters(u32);
struct Meters(u32);

fn add_mm(a: Millimeters, b: Millimeters) -> Millimeters {
    Millimeters(a.0 + b.0)
}

// Ошибка компиляции: нельзя передать Meters или просто u32
// add_mm(Meters(10), Millimeters(20));
```

**Преимущества:**
- Разные единицы измерения не перепутаешь
- Можно скрыть внутреннюю реализацию (например, `HashMap` внутри `People`)

## 2. **Псевдонимы типов** (Type Aliases)
Даём существующему типу **новое имя** для удобства, но **без проверки типов**.

```rust
type Kilometers = i32;

let x: i32 = 5;
let y: Kilometers = 10;

// Можно складывать — компилятор не ругается
let z = x + y; // ✅
```

**Где полезно:** сокращение длинных типов

```rust
type Thunk = Box<dyn Fn() + Send + 'static>;

let f: Thunk = Box::new(|| println!("Привет"));
let g: Thunk = Box::new(|| println!("Мир"));
```

**Стандартный пример:** `std::io::Result<T>` — это `Result<T, std::io::Error>`

## 3. **Тип `!` (never type)** — ничего не возвращает
Используется для функций, которые **никогда не завершаются** или прерывают выполнение.

```rust
fn panic_fn() -> ! {
    panic!("Ошибка!");
}
```

**Где применяется:**
- `continue` — возвращает `!`, поэтому в `match` можно смешивать с другими типами
- `panic!()` — тоже `!`
- `loop {}` без `break` — тип `!`

```rust
let guess: u32 = match "123".parse() {
    Ok(num) => num,
    Err(_) => continue, // continue имеет тип !
};
```

## 4. **Типы с динамическим размером (DST)** и трейт `Sized`
Некоторые типы **не имеют известного размера** на этапе компиляции:
- `str` (не `&str`)  
- трейты (`dyn Trait`)

**Проблема:**
```rust
let s: str = "привет"; // ❌ ошибка — неизвестный размер
```

**Решение:** всегда использовать **указатель**:
```rust
let s: &str = "привет";  // ✅ ссылка хранит адрес + длину
let b: Box<str> = "мир".into();
```

**Трейт `Sized`** — автоматически добавляется ко всем обобщённым типам:
```rust
fn generic<T>(x: T) {}  // неявно: T: Sized
```

Можно ослабить ограничение:
```rust
fn generic<T: ?Sized>(x: &T) {}  // T может быть DST
```

## 📌 **Итог: когда что использовать**

| Механизм | Цель | Проверка типов |
|----------|------|----------------|
| **Newtype** | Безопасность, инкапсуляция | ✅ строгая |
| **Type alias** | Удобство, сокращение кода | ❌ нет |
| **! (never)** | Функции, которые не возвращают результат | — |
| **DST + ?Sized** | Работа с типами неизвестного размера (str, трейты) | через указатели |
