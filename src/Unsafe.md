# Краткое объяснение Unsafe Rust

## Что такое Unsafe Rust?
Unsafe Rust — это режим в Rust, который отключает некоторые проверки безопасности компилятора, позволяя выполнять операции, которые не могут быть проверены статически.

## Когда использовать?
- Для низкоуровневого системного программирования
- При взаимодействии с кодом на других языках (C/C++)
- Для оптимизации производительности
- Когда компилятор не может доказать безопасность кода

## 5 "суперспособностей" Unsafe

### 1. Разыменование сырых указателей
```rust
let num = 5;
let r1 = &num as *const i32;  // неизменяемый сырой указатель
let r2 = &num as *mut i32;    // изменяемый сырой указатель

unsafe {
    println!("r1: {}", *r1);   // разыменование
    *r2 = 10;                  // изменение
}
```

### 2. Вызов небезопасных функций
```rust
unsafe fn dangerous() {
    // небезопасный код
}

unsafe {
    dangerous();  // вызов только в unsafe блоке
}
```

### 3. Работа с изменяемыми статическими переменными
```rust
static mut COUNTER: i32 = 0;

unsafe {
    COUNTER += 1;
    println!("COUNTER: {}", COUNTER);
}
```

### 4. Реализация небезопасных трейтов
```rust
unsafe trait DangerousTrait {
    fn dangerous_method(&self);
}

unsafe impl DangerousTrait for i32 {
    fn dangerous_method(&self) {
        println!("Unsafe implementation");
    }
}
```

### 5. Доступ к полям union
```rust
union MyUnion {
    int: i32,
    float: f32,
}

let u = MyUnion { int: 42 };
unsafe {
    let value = u.int;  // доступ к полю
}
```

## Пример безопасной абстракции
Создание безопасной обёртки для небезопасного кода:

```rust
// Небезопасная внутренняя реализация
fn split_at_mut(slice: &mut [i32], mid: usize) -> (&mut [i32], &mut [i32]) {
    let len = slice.len();
    let ptr = slice.as_mut_ptr();
    
    unsafe {
        assert!(mid <= len);
        (
            std::slice::from_raw_parts_mut(ptr, mid),
            std::slice::from_raw_parts_mut(ptr.add(mid), len - mid),
        )
    }
}

// Безопасный публичный интерфейс
fn main() {
    let mut numbers = vec![1, 2, 3, 4, 5];
    let (left, right) = split_at_mut(&mut numbers, 3);
    // Теперь можно безопасно использовать left и right
}
```

## Важные правила
1. `unsafe` **не отключает** проверку заимствований
2. Используйте небольшие `unsafe` блоки
3. Оборачивайте `unsafe` код в безопасные абстракции
4. Документируйте инварианты безопасности
5. Ответственность за безопасность лежит на программисте

## Когда НЕ использовать
- Если можно реализовать безопасным способом
- Без полного понимания последствий
- Для обхода ошибок компилятора без необходимости

## Итог
Unsafe Rust — мощный инструмент, но требует осторожности. Используйте его только когда действительно нужно, и всегда создавайте безопасные обёртки для небезопасного кода.
