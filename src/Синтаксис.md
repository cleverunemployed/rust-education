# Краткое объяснение синтаксиса шаблонов в Rust

## 📌 Сопоставление с литералом
Сопоставление с конкретными значениями:
```rust
let x = 1;
match x {
    1 => println!("one"),
    _ => println!("other"),
}
```

## 📌 Сопоставление именованных переменных
Переменные в шаблонах создают **новую область видимости** и затеняют внешние:
```rust
let x = Some(5);
let y = 10;
match x {
    Some(y) => println!("Matched, y = {}", y), // y = 5 (внутренняя)
    _ => println!("Default"),
}
println!("x = {:?}, y = {}", x, y); // y = 10 (внешняя)
```

## 📌 Группа шаблонов (оператор `|`)
Сопоставление с несколькими вариантами:
```rust
let x = 1;
match x {
    1 | 2 => println!("one or two"),
    _ => println!("other"),
}
```

## 📌 Диапазоны (`..=`)
Для чисел и символов:
```rust
let x = 3;
match x {
    1..=5 => println!("1-5"),
    _ => println!("other"),
}

let c = 'c';
match c {
    'a'..='z' => println!("lowercase"),
    _ => println!("other"),
}
```

## 📌 Деструктуризация

### Структуры:
```rust
struct Point { x: i32, y: i32 }
let p = Point { x: 0, y: 7 };
match p {
    Point { x: 0, y } => println!("On y axis at {}", y),
    Point { x, y: 0 } => println!("On x axis at {}", x),
    Point { x, y } => println!("At ({}, {})", x, y),
}
```

### Перечисления:
```rust
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(u8, u8, u8),
}

match msg {
    Message::Quit => println!("Quit"),
    Message::Move { x, y } => println!("Move to {}, {}", x, y),
    Message::Write(text) => println!("Write: {}", text),
    Message::ChangeColor(r, g, b) => println!("RGB: {}, {}, {}", r, g, b),
}
```

### Вложенные структуры:
```rust
enum Color { Rgb(u8, u8, u8), Hsv(u8, u8, u8) }
enum Message { ChangeColor(Color) }

match msg {
    Message::ChangeColor(Color::Rgb(r, g, b)) => println!("RGB"),
    Message::ChangeColor(Color::Hsv(h, s, v)) => println!("HSV"),
}
```

## 📌 Игнорирование значений

### Полное игнорирование (`_`):
```rust
fn foo(_: i32, y: i32) { println!("y = {}", y); }
foo(3, 4); // 3 игнорируется
```

### Игнорирование части значения:
```rust
let numbers = (2, 4, 8, 16, 32);
match numbers {
    (first, _, third, _, fifth) => println!("{}, {}, {}", first, third, fifth),
}
```

### Имена с `_` (привязывают значение):
```rust
let _x = 5; // предупреждения нет, но значение привязано
let s = Some(String::from("Hello"));
if let Some(_s) = s { } // ОШИБКА! s перемещён
if let Some(_) = s { } // OK, не перемещается
```

### Игнорирование остатка (`..`):
```rust
struct Point3D { x: i32, y: i32, z: i32 }
let p = Point3D { x: 1, y: 2, z: 3 };
match p {
    Point3D { x, .. } => println!("x = {}", x),
}

let tuple = (1, 2, 3, 4, 5);
match tuple {
    (first, .., last) => println!("{} {}", first, last),
}
// Ошибка! Неоднозначность:
// (.., second, ..) => {} // ❌
```

## 📌 Условия сопоставления (`if` guard)
Дополнительное условие после шаблона:
```rust
let num = Some(4);
match num {
    Some(x) if x % 2 == 0 => println!("Even {}", x),
    Some(x) => println!("Odd {}", x),
    None => println!("None"),
}

// Сравнение с внешней переменной:
let y = 10;
match Some(5) {
    Some(n) if n == y => println!("Matched"),
    _ => println!("Default"),
}
```

## 📌 Связывание (`@`)
Проверка и сохранение значения одновременно:
```rust
match Message::Hello { id: 5 } {
    Message::Hello { id: id_variable @ 3..=7 } => {
        println!("Found: {}", id_variable); // 5
    }
    Message::Hello { id: 10..=12 } => {
        println!("In range, but no variable"); // нет доступа к id
    }
    Message::Hello { id } => {
        println!("Other: {}", id);
    }
}
```

## 🎯 Итог

| Конструкция | Назначение |
|-------------|------------|
| `1` / `"text"` | Литералы |
| `x` / `y` | Новые переменные |
| `_` | Игнорирование без привязки |
| `_x` | Игнорирование с привязкой |
| `\|` | Альтернативные шаблоны |
| `..=` | Диапазоны |
| `..` | Игнорирование остатка |
| `if` guard | Дополнительные условия |
| `@` | Проверка + привязка |
