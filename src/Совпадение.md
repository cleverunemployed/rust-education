# Краткое объяснение: Опровержимые и неопровержимые шаблоны

## Основные понятия

**Неопровержимый (irrefutable)** шаблон — совпадает с **любым** возможным значением.  
**Опровержимый (refutable)** шаблон — может **не совпасть** с некоторым значением.

## Примеры

```rust
// НЕОПРОВЕРЖИМЫЙ — всегда совпадает
let x = 5;              // x подойдёт к чему угодно

// ОПРОВЕРЖИМЫЙ — может не совпасть
if let Some(x) = value  // если value = None, шаблон не сработает
```

## Где можно использовать

| Конструкция | Только неопровержимые | Можно оба (но предупреждение) |
|-------------|----------------------|-------------------------------|
| `let`       | ✅                    | ❌                            |
| `for`       | ✅                    | ❌                            |
| параметры функций | ✅              | ❌                            |
| `if let`    | ❌                    | ✅                            |
| `while let` | ❌                    | ✅                            |
| `match`     | ❌ (кроме последней)  | ✅                            |

## Ошибки и их исправление

**Ошибка:** используем опровержимый шаблон в `let`
```rust
let Some(x) = some_option;  // ОШИБКА! Some(x) может не совпасть
```

**Исправление:** замените `let` на `if let`
```rust
if let Some(x) = some_option {  // ✅ правильно
    println!("{}", x);
}
```

**Предупреждение:** используем неопровержимый шаблон в `if let`
```rust
if let x = 5 {  // ⚠️ ПРЕДУПРЕЖДЕНИЕ — бессмысленно, всегда совпадает
    println!("{}", x);
}
// Лучше просто: let x = 5;
```

## Правило-запоминалка

- **`let`, `for`, параметры** → только **неопровержимые**
- **`if let`, `while let`** → только **опровержимые** (иначе бессмысленно)
- **`match`** → все ветки **опровержимые**, последняя может быть **неопровержимой**
